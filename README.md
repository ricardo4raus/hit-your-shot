# Hit Your Shot: Idle Sports

A small mobile sports game: aim a line, a character shoots balls at a hole, basket or goal in short timed rounds, every hit earns money, money buys upgrades. iPhone first, Android later. Built with Expo.

Status: idea approved, design and setup phase. No game code yet.

## Read first

- `CLAUDE.md`: rules for people and AI assistants working here.
- `docs/game-design.md`: the game. Part 1 is approved, Part 2 is still open.

## Working here

Work happens on branches and lands on `main` through pull requests only, after CI passes. Keep commits small. Never put personal data (names, email addresses, phone numbers) into this repository; commit with a GitHub `noreply` address.
